# 第1行 = 桥地址（PC 端 wb-bridge.py 的地址，PC 必须和 Kindle 在同一局域网）。
#
#   怎么填：
#     同一路由器下 → 填 PC 的「WLAN IPv4 地址」（Windows: ipconfig 看 WLAN）
#     PC 开热点给 Kindle → 填热点的网关地址，常见是 192.168.137.1
#
#   ⚠️ 同一 WiFi 下的 IP 是 DHCP 动态分配的，重连 / 休眠唤醒 / 路由器重启后可能变；
#      变了就在 PC 上重新查 IP、改这里、然后重新部署插件。
#
#   远程模式（不依赖局域网，在别处也能看）：
#     把第 1 行换成 https 地址，例如
#       https://raw.githubusercontent.com/<owner>/<repo>/<branch>
#     前提是 PC 端跑着 publish_snapshot.py 定时把封面推送到那个仓库
#     （见 publish.ini.example）。此时看到的是「最近一次推送的快照」，
#     不是实时画面；PC 关机后仍保留最后一次推送的内容。
#     远程模式需要 KOReader 支持 https（ssl.https），绝大多数版本都有。
#
# 可选配置（不写就用默认值；一旦在插件菜单里改过，以菜单为准）：
#
#   theme=dark    黑底白字（默认）
#   theme=light   白底黑字 —— 墨水屏白天反光时更好读
#
# 退出常驻看板：点屏幕任意处 / 长按 / 滑动 / 上下翻页键 / 菜单里的 ✕
#
# 想用手势打开：设置 → 手势 → 添加手势 → 画一个手势 → 动作列表里选
#   「WorkBuddy 常驻看板」      （再滑一次就退出，等于开关）
#   「WorkBuddy 退出常驻看板」  （只退出）
# 装完插件重启一次 KOReader，动作才会出现在列表里。
# （插件不再自带快捷键：触屏设备上按键绑定不可用，徒增设置项。）
#
# 渲染全部在 PC 端完成，Kindle 只取一张 8 位灰度 PNG；
# 文字板不再作为可选项，仅在图片下载失败且无缓存时自动兜底。
